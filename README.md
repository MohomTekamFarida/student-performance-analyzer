
# Analyse des performances scolaires

## Présentation du projet
Ce projet a été réalisé dans le cadre de mon apprentissage du langage Python.

Il permet d'analyser les performances scolaires d'un étudiant à partir de trois notes.

## Fonctionnalités
- Saisie du nom de l'étudiant
- Saisie de trois notes
- Calcul de la moyenne générale
- Détermination du résultat : admis ou non admis

## Technologies utilisées
- Python 3
- GitHub

## Objectif pédagogique
Mettre en pratique les bases de Python : variables, saisie de données, calculs, conditions et affichage des résultats.
